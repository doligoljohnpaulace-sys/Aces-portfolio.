Upload **everything inside this folder** to a GitHub repository:

```
index.html        <- home page (must stay at the top level)
arduino.html      <- Arduino project information page
css/style.css
js/script.js
images/           <- profile + Arduino photos
videos/arduino-demo.mp4
files/John-Paul-Ace-Doligol-Resume.pdf
```

## Publish with GitHub Pages
1. Sign in at github.com, click **New repository**, name it (e.g. `portfolio`), keep it **Public**, click **Create repository**.
2. Click **uploading an existing file**, drag in all files and folders listed above (keep the folder structure), then **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. Wait 1–2 minutes and refresh. Your site link appears at the top of that page: `https://YOUR-USERNAME.github.io/portfolio/`.
